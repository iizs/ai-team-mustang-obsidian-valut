기본은 평범한 차량 비용 관리 일지, 속칭 차계부
drivvo 라는 앱이 좋은 참고가 될거야. 

차별점은 영수증 사진을 찍으면 입력 폼을 기본으로 채워준다는 것
즉 보통의 차계부 앱이 다음과 같은 동작이라면 
* 입력할 항목 선택 (주유, maintenance, toll 등) -> 각 항목에 맞는 입력폼 오픈 -> 사용자가 입력 폼을 채워서 저장
이 앱의 플로우는 다음 두 가지 정도가 가능할거야
* 입력할 항목 선택 (주유, maintenance, toll 등) -> 각 항목에 맞는 입력폼 오픈 + 사진 촬영 버튼 -> 사진 촬영을 선택하면 사용자가 영수증을 촬영 -> 앱은 AI로 영수증의 항목을 분석해서 입력 폼의 알맞은 위치에 내용을 채움 -> 사용자가 입력된 내용을 검토하고, 필요하면 수정한 다음 저장
* 사용자가 영수증 사진을 촬영 -> 앱이 AI를 사용하여 영수증이 어떤 종류의 영수증인지 판단 -> 유효한 영수증이라 판단되면 해당 영수증에 맞는 입력폼을 오픈하고, 내용을 채워줌 -> 사용자가 입력된 내용을 검토하고, 필요하면 수정한 다음 저장

iOS / 안드로이드 앱으로 만들거고 웹은 고민하지 않고 있어. 
단, 두 앱을 모두 만들기는 곤란할테니, flutter 로 만들도록 하자. flutter 테스트가 먼저이려나

- **차계부 입력 마찰 제거** — AI 자동입력이 유일한 차별점
- 항목 선택 없이 영수증 사진부터 찍는 플로우 (두 번째 플로우)가 UX상 더 자연스러움
