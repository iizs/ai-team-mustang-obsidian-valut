## SC-81 본문 정정 사유

**충돌**: SC-81 작성 시 "page_path/description 필수" 표현 사용. 그러나 ADR-0018 데이터 모델 본문엔:

```
page_path varchar,  -- nullable (예: 위키 전체 통계 finding)
```

명시적으로 nullable + 사유(위키 전체 통계 finding)까지 설명. **ADR이 의도적으로 page_path optional로 설계한 것**을 SC 작성 시 놓침.

구현은 ADR을 따라 `Optional[str]`로 작성 → 정합. SC 본문이 후행 작성되었으므로 SC를 ADR에 맞춰 정정함.

**정정 내용** (success-criteria.md):
- `page_path: str` → `page_path?: str` (optional)
- "`page_path`/`description` 필수" → "`description` 필수, `page_path`는 optional (ADR-0018 데이터 모델 정합)"
- 본문에 사용자 신고 UI는 항상 현재 page_path 첨부함 명시

**구현 영향**: 없음. 정정 후 구현이 SC와 정합.

**교훈**: SC 작성 시 ADR 데이터 모델 본문을 더 정확히 반영해야 함. v0.4 SC-54/58 패턴 재발(SPEC 표현 vs 구현 의도 차이) — Hawkeye 작성 프로세스에 ADR 데이터 모델 칸 단위 비교 단계 추가 가치.
