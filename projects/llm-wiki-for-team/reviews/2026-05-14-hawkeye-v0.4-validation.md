### Blocking 2건 (1차)

**SC-71 — `last_updated` 자동 갱신 누락**
- `wiki_store.update_last_updated()` 정의는 있는데 `tools._exec_write_page`/`_exec_patch_page`에서 호출 안 됨
- 사용자가 Properties에서 페이지 최신 변경 시점 못 봄

**SC-78 — 매 step commit 미구현**
- `_finalize_commit`이 job 완료 후 단일 commit으로 모든 변경 묶음
- SPEC: 매 write/patch/delete = 1 commit + 메시지 `[job:<id> step:<n>] <tool>: <path>`
- 영향: git history로 step별 변경 추적 불가

### Breda 핫픽스 (`b9d2010`)

- `tools._exec_write_page`/`_exec_patch_page`에서 `update_last_updated()` 호출
- `ToolContext.step_counter` 추가 + `_commit_step()` 헬퍼
- 각 write tool 자체 commit + commit 메시지 패턴 적용
- `_finalize_commit`은 index.md + log.md만 closing commit
- 신규 테스트 3건 (`test_sc71_*`, `test_sc78_*`)
