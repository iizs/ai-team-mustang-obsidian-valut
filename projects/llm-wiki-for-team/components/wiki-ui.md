# Wiki UI

Web 기반 위키 조회 + 수정 요청 + Job 상태 추적 UI.

## 화면 구성

| 경로 | 설명 | 권한 |
|------|------|------|
| `/login` | JWT 로그인 | 공개 |
| `/signup` | 자가 가입 (v0.2) | 공개 |
| `/wiki` | 페이지 목록 + ZIP 다운로드 | 인증 |
| `/wiki/[...slug]` | 페이지 조회 + 하단 Edit 입력창 | 인증 |
| `/sources` | 원본 목록/다운로드 (Admin: 업로드) | 인증 |
| `/jobs` | Job 목록/상태 (페이징, Admin: 전체 / Member: 본인) | 인증 |
| `/admin/users` | 사용자 관리 (목록, role 변경, 비활성화) — v0.2 | Admin |
| `/guide` | 로컬 연동 가이드 | 인증 |

## 위키 페이지 조회 규칙

- **읽기 전용**: 텍스트 직접 편집 불가
- **노출 순서 (v0.2)**: 위에서 아래로
  1. 본문 (Markdown 렌더링)
  2. 페이지 속성 (frontmatter, 표 형식, 기본 접힘)
  3. 수정 요청 입력창
- **수정 요청 입력창**: 페이지 하단 고정. 해당 페이지 단일 컨텍스트로 EDIT Job 생성
  - 다중 페이지에 걸친 요청은 MVP 범위 외
- **페이지 속성 (frontmatter, v0.2)**: 본문과 분리된 영역에 표 형식으로 노출. 기본 접힘. `sources`는 다운로드 가능한 링크로 렌더링.
- **`[[페이지명]]` 링크**: v0.1은 plain text로 보임. v0.2에서 클릭 가능 링크로 변환 (SC-20 Blocking 승격)

## Jobs 탭

- Job 목록 + 상태 (Pending / Processing / Done / Failed)
- 요청 전문, 처리 결과(수정된 페이지), 에러 메시지 포함
- Admin: 전체 / Member: 본인 요청만
- **페이징 (v0.2)**: default 20건/페이지, 클라이언트에서 변경 가능
