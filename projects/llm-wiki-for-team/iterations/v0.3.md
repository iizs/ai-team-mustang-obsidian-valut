## 기간 / 상태

2026-05-08 ~ ? / **In Progress** (Kirin 승인 2026-05-08)

## 목표

Ingest 파이프라인이 **기존 위키 구조를 인지하고 분해 plan을 출력**하도록 한다. 같은 주제 중복 페이지 발생을 줄이고, 향후 분리/통합(merge/supersede) 도입의 기반을 마련한다. 추가로 환경 초기화 스크립트를 도입해 운영·테스트 사이클을 빠르게 한다.

## 환경 초기화 스크립트 명세

**파일**: `backend/scripts/init_env.py` (`seed_admin.py` 삭제)

**동작**:
- Interactive prompt 기반, 환경변수 또는 인자가 있으면 그 값을 default로 미리 채움
- DB 스키마 (`create_all` — 없을 때만)
- Source store 디렉토리 생성
- Wiki store 디렉토리 + git init + `index.md`/`log.md`/`_sheska.yaml` 초기화
- Admin 계정 생성 (이메일/패스워드)

**옵션**:
- `--reset` — DB 파일 + source store + wiki store 모두 삭제 후 재생성 (테스트용)
- `--admin-email`, `--admin-password` — interactive prompt 기본값 채우기
- `--non-interactive` — 모든 값을 인자/환경변수에서 가져오고 prompt 생략 (CI 등)

**환경변수 fallback**:
- `INITIAL_ADMIN_EMAIL`, `INITIAL_ADMIN_PASSWORD` — interactive 기본값 또는 non-interactive 모드 입력

## Plan 스키마 (ADR-0011 발췌)

```json
[
  {"action": "create",
   "page_path": "<kebab-case>.md",
   "content": "<full markdown including frontmatter>"},
  {"action": "merge_into",
   "target": "<existing-page>.md",
   "merged_content": "<full new content>"},
  {"action": "supersede",
   "target": "<existing-page>.md",
   "reason": "...",
   "new_content": "<full new content>"}
]
```

Phase A에서는 `create`만 실행. 나머지는 `log.md`에 "skipped (phase A)" 표시.
