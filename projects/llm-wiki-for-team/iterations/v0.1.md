# v0.1 — MVP

## 기간 / 상태

2026-05-05 ~ 2026-05-07 / **Done**

## 목표

자체호스트 가능한 llm-wiki 솔루션 MVP. 사용자가 PDF/TXT/MD 원본을 투입하면 LLM이 Obsidian MD 위키를 자동 생성/수정하고, 팀이 git/zip으로 받아 에이전트가 사용 가능.

## 스코프

**포함:**
- 인증 (이메일/패스워드 + JWT, Admin/Member 2-role)
- 비동기 Job Queue (INGEST/EDIT, FastAPI BackgroundTasks)
- 원본 투입 (PDF/TXT/MD)
- LLM Pipeline (Ingest/Edit, index.md/log.md 자동 관리)
- Web UI (조회 + Edit 입력 + Jobs 탭 + Source 메뉴)
- 로컬 Sync (git clone/pull, zip)
- 배포 (Docker Compose: backend + frontend + nginx git server)
- 로컬 연동 가이드

**제외 (v0.2+로 보류):**
- Lint (이유: 위키 규모/비용 검증 후 도입)
- 원본 soft-delete (이유: 영향 범위 판단 복잡, MVP 핵심 가치 외)
- DOCX, URL 크롤링 (이유: 파싱/외부 의존성 부담)
- 권한 세분화 (이유: 2-role로 충분, Casbin은 v0.2+ 마이그레이션 가능성으로 메모)
- SSO, 멀티테넌시 (이유: MVP 검증 후)
