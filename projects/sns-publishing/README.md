# sns-publishing

_2026-09-27 착수 · 담당: Falman_

Kirin이 쓴 글을 Falman이 검토·번역하고 여러 SNS에 발행하는 흐름. 원고와 진행 상황은 Dooray `SNS-Publishing` 프로젝트(`4429251819650654485`)에서 관리한다. 발행은 API 대신 Claude in Chrome 브라우저 제어로 한다. 이전에 API 방식은 토큰 만료와 플랫폼 제약이 많았기 때문이다.

## 공통 원칙

- 브라우저: Claude in Chrome, **"Chrome for Falman" 프로필**만 사용. 세션은 `claude --chrome --remote-control falman`으로 시작.
- 로그인: 되어 있다고 가정한다. 로그인 화면이나 본인 확인 요구를 만나면 **즉시 중지하고 Kirin에게 리포트**한다. Falman은 로그인하지 않는다 (저장된 비밀번호 자동완성 포함).
- 발행 승인: 세션 채팅(터미널 또는 Remote Control)으로만 받는다. 승인 목록에 없는 게시는 하지 않는다.
- 플랫폼별 발행 절차는 Claude Code 스킬로 분리한다 (`agent-falman/.claude/skills/publish-<platform>/`).

## 플랫폼 스킬

| 스킬 | 상태 |
|---|---|
| `publish-facebook` | 임시저장·예약 검증 완료, 즉시 게시 미검증 |
| `publish-linkedin` | 예정 |
| `publish-wordpress` | 드래프트 검증 완료 (WordPress.com) |

## publish-facebook 스펙

**입력**
- 본문 텍스트 (필수)
- 이미지 파일 경로 목록 (선택, 로컬 경로. Dooray 첨부는 `task-file-download`로 먼저 받는다)
- 공개 범위: 기본 `전체 공개`, 테스트 중에는 `나만 보기`

**계정 구조**
- 하나의 로그인으로 두 프로필을 오간다. 전환은 화면 오른쪽 위 프로필 메뉴에서 한다.
  - `Choi Kirin`: 개인 프로필. **Falman이 게시하지 않는다.**
  - `Choi Kirin / 최기린`: 공개 페이지. **Falman의 게시 대상.**
- 게시 전 현재 활성 프로필이 `Choi Kirin / 최기린`인지 반드시 확인하고, 아니면 전환한다.

**절차**
1. facebook.com 접속 → 로그인 상태 확인 (아니면 중지·리포트)
2. 활성 프로필 확인 → 필요하면 `Choi Kirin / 최기린`으로 전환
3. 게시물 작성창 열기 → 본문 입력 → 이미지 첨부
4. 공개 범위 설정 (테스트: `나만 보기`)
5. 게시 전 입력 내용과 프로필, 공개 범위를 스크린샷으로 확인
6. 게시 → 게시물 URL 확보
7. 결과(URL, 프로필, 공개 범위) 리포트. Dooray 태스크에서 실행한 경우 댓글로 기록

**중지 조건 (리포트 후 대기)**
- 로그인 안 됨, 본인 확인·보안 점검 요구
- 프로필 전환 실패 또는 활성 프로필을 확정할 수 없음
- 요청한 공개 범위를 선택할 수 없음 (특히 테스트 중 `나만 보기`가 없을 때 전체 공개로 올리지 않는다)
- 예상과 다른 UI로 절차를 진행할 수 없음

## publish-wordpress 스펙

**대상**: WordPress.com 블로그 `https://kirinchoi.wordpress.com/wp-admin/`. 영문으로 운영한다.

**입력**
- 원고: **영문 번역본** (필수). 보통 번역 태스크의 최종 번역본을 지정받는다.
  - 한글 원고로 업로드를 지시받으면 진행하지 않는다. 태스크에 "번역본을 지정해달라"고 댓글을 달고 Kirin에게 돌려보낸다.
- 제목: Kirin이 제공한다. 없으면 Falman이 하나 추천해 그 제목으로 드래프트를 만들고, 추천한 제목임을 리포트에 밝힌다.
  - 원고 첫 줄이 제목(`# ...`)이면 제목 입력칸으로 옮기고 본문에서는 뺀다.
- 이미지: 선택. 첨부를 지시받은 경우에만 사용한다.
- 카테고리, 태그, 이미지 대체 텍스트: 태스크에 지정된 경우에만 넣고, 없으면 비워둔다 (2026-09-27 결정).

**범위**: 드래프트 저장까지. 게시는 CLAUDE.md 발행 규칙대로 Kirin이 직접 하거나 세션 채팅으로 지시한다.

**절차**
1. `wp-admin` 접속 → 로그인 상태 확인. 로그인이 풀려 있으면 **중지하고 Kirin에게 로그인을 요청**한다.
2. 이미지가 있으면 먼저 **Media 라이브러리에 업로드**한다.
3. Posts → Add New(글쓰기)로 에디터(블록 에디터)를 연다.
4. 제목 입력.
5. 이미지가 있으면:
   - 업로드한 미디어를 **Featured image**로 지정한다.
   - 본문 **맨 위**에 같은 이미지를 **가운데 정렬** 이미지 블록으로 넣는다. 새로 올리지 않고 Media 라이브러리에서 가져온다.
6. 본문 입력.
7. **Save draft**. 드래프트 목록에서 저장을 확인한다.
8. 리포트: 제목(추천 여부), 이미지 처리 결과, 드래프트 위치를 태스크 댓글로 남긴다.

**중지 조건**: 로그인 풀림, 한글 원고로 지시받음, 이미지 업로드 실패, 에디터 UI가 예상과 달라 진행할 수 없음.
