## Task Hub receiver PoC 검증 완료 · dooray-skill v0.4 hooks

**남은 결정**: A3 v0.2(라우팅) 진행 방향 · Monitor 채널(WS vs FIFO) 결정 · agent name 매핑 소스.

## receiver v0.2 구현 · 실증 완료

[[projects/mustang-task-hub/README]] v0.2 구현 완료. 모듈 재편(config/dooray_client/member_cache/router/sources/ws_manager/archiver/log_setup/main). Sandbox 대상 실증 3가지 통과: (1) Roy가 자기 assign → open-api + source=roy = self-loop skip, (2) Roy가 kirin assign → target=kirin 정상 라우팅 (WS 세션 없어 delivered=0), (3) 시뮬레이션 payload로 Kirin comment → Roy WS로 fan-out 1건 배달 (consumer 수신 확인).
