## Task Hub receiver PoC 검증 완료 · dooray-skill v0.4 hooks

[[projects/mustang-task-hub/README]] 신규 프로젝트 착수 (private 리포 `iizs/mustang-task-hub`). FastAPI + Docker Compose PoC receiver 로 Cloudflare Quick Tunnel 뒤에서 Dooray Sandbox 이벤트 4/4 수신 검증. [[projects/dooray-skill/README]] v0.4로 `hooks.create` 추가 — hook 등록에 프로젝트 admin 권한 필요 확인 (Roy 승격 후 성공). [[projects/team-operations-rework/README]] Track A3 상태 PoC 완료로 갱신, 결정 기록 2건 추가.

관찰 두 개는 문서화 완료: (1) 실제 payload는 `hookVersion`이 아닌 `version` 필드로 옴 (문서 discrepancy), (2) `requestOrigin.type=open-api` 를 self-loop 방지 필터로 활용 가능.

**남은 결정**: A3 v0.2(라우팅) 진행 방향 · Monitor 채널(WS vs FIFO) 결정 · agent name 매핑 소스.

## mustang-task-hub v0.2 스펙 확정

[[projects/mustang-task-hub/README]] v0.2 진화 섹션에 결정 매트릭스 8개 (매핑 · 채널 · 엔드포인트 · 인증 · self-loop · archival · health · 로깅) + skip 결정 (in-memory 버퍼) 정리. 환경변수 리스트(receiver 9개, agent session 1개) 명시. Cloudflare tunnel은 receiver 밖 별도 실행 (Quick Tunnel URL 휘발 특성). 매핑 규약: `userCode == agent name`, `mapping.yaml`로 오버라이드. Monitor 채널: WebSocket per agent, fan-out 정책.

**남은 결정**: 구현 착수 후 발견되는 세부 (예: mapping.yaml 스키마, WS 재연결 정책 세부, self-loop 필터 판단 세부).
