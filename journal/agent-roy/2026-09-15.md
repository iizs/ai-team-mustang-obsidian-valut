## Plugin monitor 스키마 실증 · Path Y 확정 · human 필터 추가

Plugin monitor 매니페스트 실증 완료 (`--debug-file`로 zod validation 에러 확인). `ws:` 는 unrecognized_keys, `command` 만 인식 → **Path Y 확정**. WS consumer 스크립트 프로토타입 실증 성공 (수신 → stdout 한 줄 요약). 실패 시 monitor 만 조용히 drop, 플러그인 나머지 요소는 로드 정상. [[projects/mustang-agent-plugin/README]] 결정 기록 3건 · 미결 3건으로 갱신.

**Human 필터** 요구사항 반영: `mustang-task-hub c9e587f`에 `TASK_HUB_HUMAN_AGENTS` env 추가. `kirin` 을 사람으로 지정, Roy → Kirin 태스크 생성 → target=kirin(human) → skip 확인 (`dropped_human=1`, `route.human_skipped` 로그). Dooray 자체 알림에 위임.

**남은 결정**: task-hub-loop skill 위치 · CLAUDE.md 트리거 명시 수준 · 실패 코멘트 표준.
