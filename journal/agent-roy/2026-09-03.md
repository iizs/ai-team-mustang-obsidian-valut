## 저널 skill 도입

인라인 저널 규칙을 CLAUDE.md에 실어놓으면 매 세션 컨텍스트를 먹고, 트리거 폭이 넓으면(결정/커밋/승인 요청 등) 한 세션이 3~4 append로 부풀어지는 문제. `~/.claude/skills/journal/SKILL.md`로 저널링 프로시저를 옮기고 세 에이전트 CLAUDE.md엔 짧은 포인터만 남김. Skill 인자로 `agent=<이름>` 항상 명시, frontmatter의 `topics`/`tags`는 리스트로 같은 날 파일에서 병합. 자동 트리거 기준은 미확정 — 지금은 매뉴얼만. 이 항목 자체가 skill 스펙의 첫 실증(다음 세션부터 실제 skill invoke).
